# Digital Business Health Check Survey — Start Daily

A lightweight, fully responsive, interactive multi-step survey designed to help businesses evaluate their online footprint, digital hurdles, and website health.

## ✨ Features
- **Dynamic 5-Step Interface:** Seamless progression tracking with a visual percentage loader.
- **Dual Theme Support:** Smooth transition between dark mode and light mode with local persistence.
- **Smart Conditional Visibility:** Intuitively shows or hides context-based fields (e.g., custom role input).
- **Secure Architecture:** Frontend validation checks preventing incomplete submission errors.

## 🛠️ Built With
- Semantic HTML5
- Custom CSS3 variables for clean theme architecture
- Pure vanilla JavaScript (No bloated external dependencies)
